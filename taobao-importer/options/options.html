ブランド管理

ブランドごとに「管理番号の頭文字」「価格の計算ルール」「タイトルの変換ルール」を持てます。
商品の取り込み時に、どのブランドとして登録するかを選びます。

価格の計算ルール

元価格に、上から順に計算が適用されます。行の追加・削除で自由に組み替えられます。
外貨のサイト（Taobaoなど）は換算レートを設定してください。日本円のサイトは「1」のままでOKです。

順番計算の種類数値

タイトルの変換ルール

元のタイトルに ①削除 → ②置き換え → ③並べ替え の順で適用されます。

このブランド専用のSNS投稿テンプレート（空欄 = 下の共通テンプレートを使う）

共通テンプレートでも {{brand}} にブランド名が自動で入るので、 文面そのものを変えたいブランドだけここに書けばOKです。

仕入れ先サイト

1行に1つ書いてください。取り込み時の選択肢になります。

共通設定

X自動投稿システム用CSV（products.csv）の列構成

「📤 X連携用に出力」で作られる products.csv の列を、上から順に1行1列で書きます。
既存の products.csv の列に合わせて、並び替え・削除・追加してください。
使える列名： id（管理番号） brand product_name（販売タイトル） original_title price（販売価格円） original_price（元価格） list_price（元の定価） currency product_url product_id image（1枚目の画像ファイル名） images（全画像 |区切り） color size post_text（SNS投稿文） supplier created_at

SNS投稿文テンプレート

使える置き換えワード： {{code}} 管理番号 / {{brand}} ブランド名 / {{title}} 販売タイトル / {{priceJpy}} 販売価格 / {{priceOriginal}} 元価格 / {{colors}} カラー / {{sizes}} サイズ / {{url}} 商品URL
