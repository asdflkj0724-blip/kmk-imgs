# ワンクリック商品取り込み Chrome拡張（汎用版）

自分でブラウザに開いている **商品ページ1件だけ** を、
ボタンを1回押したときに取り込んで保存するChrome拡張機能です。
特定のブランド・特定のサイト専用ではなく、複数の通販サイトで使えます。

取り込んだ商品は、既存の **X自動投稿システム**（products.csv ＋ images フォルダ
＋ GitHub Actions）に渡せる形式（products.csv と MAMC-000001-01.jpg 形式の画像）で
出力できます。既存システム側のファイルには一切触りません。

- 自動巡回・大量取得・バックグラウンドでのページ閲覧は **一切しません**
- CAPTCHAやアクセス制限を回避する機能は **ありません**
- ボタンを押した瞬間に、いま見ているページのHTMLから情報を読むだけです
- データはすべて拡張機能の中（`chrome.storage.local`）に保存され、外部には送信しません

## どうやって「どのサイトでも」動くのか

情報は次の順番で探します。多くの通販サイトは②③の共通データを持っているので、
専用の設定なしでもかなりの確率で取り込めます。

1. **サイト専用プロフィール**（`content/selectors.js` に登録したサイトのみ。Taobao/Tmallは登録済み）
2. **JSON-LD**（多くのサイトがページに埋め込んでいる商品データ）
3. **OGPメタタグ**（og:title、og:image など）
4. **一般的なセレクタ**（h1 や .price など）

うまく取れないサイトがあったら、`content/selectors.js` の末尾のコメントの形で
そのサイト用のプロフィールを1つ追加すれば対応できます。

## フォルダ構成（どのファイルが何をしているか）

```
taobao-importer/
├── manifest.json        拡張機能の設定ファイル（権限・入口の定義）
├── popup/               ツールバーのアイコンを押すと開く画面
│   ├── popup.html       画面のレイアウト（ボタン・確認画面・一覧）
│   ├── popup.css        見た目
│   └── popup.js         画面の動き（取り込み→確認→保存の流れ）
├── content/             商品ページに一時的に注入されるスクリプト
│   ├── selectors.js     ★サイト別プロフィール集。サイト対応はここに追加
│   └── scraper.js       汎用の読み取り処理（JSON-LD/OGP/セレクタ）
├── lib/                 共通ロジック（画面を持たない部品）
│   ├── config.js        ブランド・仕入れ先・SNSテンプレートの初期値
│   ├── price.js         ★価格ルールの計算 calculateSellingPrice()
│   ├── title.js         ★タイトル変換ルール buildProductTitle()
│   ├── storage.js       保存・ブランド別の管理番号採番・重複チェック
│   ├── sns.js           SNS投稿文の生成
│   └── export.js        JSON / CSV 出力
└── options/             設定画面（ブランド・価格ルール・タイトルルール等）
    ├── options.html
    ├── options.css
    └── options.js
```

## セットアップ（Chromeに読み込む）

1. このフォルダ（`taobao-importer`）をパソコンの好きな場所に置く
2. Chromeのアドレスバーに `chrome://extensions` と入力して開く
3. 右上の「**デベロッパーモード**」をONにする
4. 「**パッケージ化されていない拡張機能を読み込む**」→ `taobao-importer` フォルダを選ぶ

✅ 一覧に「ワンクリック商品取り込み」が表示されればOKです。

> 旧バージョン（MAMC Taobao専用）から更新した場合は、拡張の「🔄再読み込み」を
> 押すだけでOK。保存済み商品と連番は自動でMAMCブランドに引き継がれます。

> コードを修正したときは、`chrome://extensions` でこの拡張の
> 「🔄（再読み込み）」ボタンを押すと反映されます。

## 使い方の流れ

1. 商品ページを普通にブラウザで開く（Taobaoでも、日本のサイトでもOK）
2. 拡張機能のアイコンを押して「📥 この商品を取り込む」
3. 確認画面で：
   - **ブランド**と**仕入れ先サイト**を選ぶ（ブランドを変えると価格とタイトルが計算し直されます）
   - 販売タイトル・価格などを確認、必要なら手で修正
   - 保存したい画像だけチェックを残す（すべて選択／すべて解除あり）
4. 「💾 この内容で保存する」→ ブランドごとの管理番号（MAMC-000001、OLDORDER-000001…）が付く
5. SNS投稿文が表示されるのでコピーして使う
6. ホーム画面からいつでも JSON / CSV 出力、SNS文コピー、削除ができる

同じ商品（同じ商品ID または同じURL）をもう一度取り込もうとすると
「この商品はすでに登録されています」と表示されます。

## 設定画面（⚙）でできること

### ブランド管理
- 最初から MAMC / Old Order（OLD） / FVVO / その他（OTHER）が入っています
- ブランドの追加・削除（いくつでも）
- ブランドごとの**管理番号の頭文字**（MAMC → MAMC-000001、OLD → OLD-000001）
- ブランドごとの**SNS投稿テンプレート**（空欄なら共通テンプレートを使い、{{brand}} に自動でブランド名が入る）
- ブランドごとの**価格ルール**：
  - 換算レート（外貨サイト用。日本円のサイトは 1 のまま）
  - 計算ステップを自由に並べる：「＋円」「−円」「×倍」「＋％」
  - 丸め単位（100 → 100円単位で切り上げ）
  - 元価格を入れると販売価格が出る**プレビュー付き**
- ブランドごとの**タイトル変換ルール**：
  - ① 削除したい文字（例: 2024新款, 送料無料）
  - ② 置き換え（例: `卫衣=>パーカー`）
  - ③ 並び順（例: `{{brand}} {{title}}` → 「MAMC メンズ パーカー…」）
  - こちらも**プレビュー付き**

### その他
- 仕入れ先サイトのリスト（1行1件）
- 管理番号の連番の桁数
- **X連携用CSV（products.csv）の列構成**（1行1列。既存の products.csv に合わせて並び替え・追加・削除できる）
- 共通のSNS投稿文テンプレート（`{{code}}` `{{brand}}` `{{title}}` `{{priceJpy}}` `{{priceOriginal}}` `{{colors}}` `{{sizes}}` `{{url}}` が使えます）

## 既存X自動投稿システムとの接続方法

この拡張は既存システムの「前段」です。最初のバージョンでは自動送信はせず、
**既存システムがそのまま読める形のファイルを手元に作る**ところまでやります。

1. ホーム画面の「📤 X連携用に出力」を押す
2. パソコンの**ダウンロードフォルダ**に次が作られます：
   ```
   x-post-export/
   ├── products.csv                ← 列構成は設定画面で変更可（post_text にSNS投稿文入り）
   └── images/
       ├── MAMC-000001-01.jpg      ← 管理番号-連番.jpg
       ├── MAMC-000001-02.jpg
       └── OLD-000001-01.jpg
   ```
3. `products.csv` の行を既存リポジトリの products.csv に追加し、
   `images/` の中身を既存リポジトリの images フォルダにコピーして、
   いつも通り GitHub にアップすれば、既存の GitHub Actions がXへ投稿します

※1商品だけ渡したいときは、保存完了画面や一覧の「画像DL」でその商品の画像だけ保存できます。
※将来「GitHubへ自動送信」を追加するときは `lib/` に連携ファイルを足すだけで済む構成です。

## 動作確認の手順（変更後に1つずつ試す）

1. **読み込み直し**：`chrome://extensions` → 🔄再読み込み。名前が「ワンクリック商品取り込み」になっていればOK
2. **設定画面**：⚙設定を開く → ブランドに「MAMC」「Old Order」が入っている。
   「＋ブランドを追加」で試しに1つ追加 → 保存 → 表示が増えればOK
3. **価格ルール**：MAMCを選び、プレビューの元価格に100を入れる → 「販売価格 ¥5,500」と出ればOK。
   計算行を増減させてプレビューが変わることも確認
4. **タイトルルール**：削除欄に「2024新款」、置き換え欄に「卫衣=>パーカー」と入れる →
   プレビューが「MAMC メンズ パーカー 上下セット」になればOK
5. **取り込み（Taobao）**：Taobaoの商品ページで「この商品を取り込む」→
   確認画面でブランドMAMC・仕入れ先Taobaoが選ばれ、価格・画像が出ればOK
6. **取り込み（他サイト）**：日本の通販サイトの商品ページでも同じ操作 →
   タイトル・価格・画像が取れることを確認（通貨がJPYなら換算レート1のブランドを選ぶ）
7. **保存**：保存して管理番号がブランドの頭文字で始まること（MAMC-000001 / OLD-000001…）、
   同じページをもう一度取り込むと重複エラーが出ることを確認
8. **出力**：CSV出力を開き、「ブランド」「仕入れ先」「元タイトル」列があることを確認
9. **X連携出力**：「📤 X連携用に出力」→ ダウンロードフォルダに
   `x-post-export/products.csv` と `x-post-export/images/MAMC-000001-01.jpg` ができることを確認。
   products.csv をExcel等で開き、設定画面の列構成どおりの列＋post_text にSNS投稿文が入っていることを確認

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| ボタンを押しても何も起きない | ページを一度再読み込み（F5）してから再度押す |
| 価格やタイトルが取れないサイトがある | F12→Consoleの `[商品取り込み]` ログで何が取れたか確認。`content/selectors.js` にそのサイトのプロフィールを追加 |
| 画像が少ない | 商品ページを一番下までスクロールしてから取り込む（説明画像は遅延読み込みのため） |
| コード修正が反映されない | `chrome://extensions` で拡張の🔄再読み込み＋商品ページもF5 |

## 将来の拡張について

Googleスプレッドシート・Instagram・X・BUYMA連携などを追加するときは、
`lib/` に新しいファイル（例: `sheets.js`）を追加し、`storage.js` の
`getProducts()` で商品データを読み出して送る、という作りを想定しています。
既存ファイルはほぼ触らずに機能追加できます。
