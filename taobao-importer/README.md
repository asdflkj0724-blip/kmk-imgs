# MAMC Taobao 商品取り込み Chrome拡張

自分でブラウザに開いている **Taobao / Tmall の商品ページ1件だけ** を、
ボタンを1回押したときに取り込んで保存するChrome拡張機能です。

- 自動巡回・大量取得・バックグラウンドでのページ閲覧は **一切しません**
- CAPTCHAやアクセス制限を回避する機能は **ありません**
- ボタンを押した瞬間に、いま見ているページのHTMLから情報を読むだけです
- データはすべて拡張機能の中（`chrome.storage.local`）に保存され、外部には送信しません

---

## フォルダ構成（どのファイルが何をしているか）

```
taobao-importer/
├── manifest.json        拡張機能の設定ファイル（権限・入口の定義）
├── popup/               ツールバーのアイコンを押すと開く画面
│   ├── popup.html       画面のレイアウト（ボタン・確認画面・一覧）
│   ├── popup.css        見た目
│   └── popup.js         画面の動き（取り込み→確認→保存の流れ）
├── content/             商品ページに一時的に注入されるスクリプト
│   ├── selectors.js     ★セレクタ集。Taobaoの構造が変わったらここだけ直す
│   └── scraper.js       商品名・価格・画像などを実際に読み取る処理
├── lib/                 共通ロジック（画面を持たない部品）
│   ├── config.js        設定の初期値・SNSテンプレートの初期値
│   ├── price.js         ★日本円販売価格の計算式 calculateSellingPrice()
│   ├── storage.js       保存・管理番号の採番・重複チェック
│   ├── sns.js           SNS投稿文の生成
│   └── export.js        JSON / CSV 出力
└── options/             設定画面（為替レート・利益率・テンプレート等）
    ├── options.html
    ├── options.css
    └── options.js
```

★印の2ファイルが「あとから一番よく触ることになる」ファイルです。

## STEP 1〜2：Chromeに読み込む（最初にやること）

1. このフォルダ（`taobao-importer`）をパソコンの好きな場所に置く
2. Chromeのアドレスバーに `chrome://extensions` と入力して開く
3. 右上の「**デベロッパーモード**」をONにする
4. 「**パッケージ化されていない拡張機能を読み込む**」を押す
5. `taobao-importer` フォルダを選ぶ

✅ **動作確認**：一覧に「MAMC Taobao 商品取り込み」が表示され、
ツールバーのパズルピース🧩アイコンから拡張機能をピン留めできればOKです。

> コードを修正したときは、`chrome://extensions` でこの拡張の
> 「🔄（再読み込み）」ボタンを押すと反映されます。

## STEP 3：ボタンを表示する

1. Taobaoの商品ページ（URLが `item.taobao.com/item.htm?id=...` など）を普通に開く
2. ツールバーの拡張機能アイコンをクリック

✅ **動作確認**：「📥 この商品を取り込む」ボタンが表示されればOK。
Taobao以外のページで押すと「Taobaoの商品ページを開いた状態で押してください」と出ます。

## STEP 4〜5：商品情報・画像を取得する

1. 商品ページで「この商品を取り込む」を押す

✅ **動作確認**：確認画面に商品名・価格・URL・商品ID・カラー・サイズと、
画像のサムネイル一覧が表示されればOK。

うまく取れないときは、商品ページで **F12 → Console タブ** を開くと
`[MAMC取り込み]` で始まるログが出ています。取得結果がそこに全部表示されるので、
何が取れて何が取れなかったか確認できます。

> 取れない項目がある場合は `content/selectors.js` を直します（直し方はファイル内にコメントで説明があります）。

## STEP 6：確認画面で修正・画像選択

✅ **動作確認**：
- 商品名や価格を書き換えられる
- 画像をクリック（またはチェックボックス）で選択/解除できる
- 「すべて選択」「すべて解除」が効く
- 「n / m 枚選択中」の数字が変わる

## STEP 7：保存する

1. 確認画面で「💾 この内容で保存する」を押す

✅ **動作確認**：
- 「保存しました 管理番号：MAMC-000001」と表示される
- ホームに戻ると保存済み一覧に商品が出ている
- **同じ商品ページでもう一度取り込むと「この商品はすでに登録されています」と出る**
- 「JSON出力」「CSV出力」でファイルがダウンロードできる（CSVはExcelでそのまま開けます）

## STEP 8：日本円価格の自動計算

初期設定は「1元=22円、送料2,000円、利益率30%、100円単位切り上げ」です。
例：100元 → 100×22=2,200円 → +送料2,000円=4,200円 → ×1.3=5,460円 → **¥5,500**

✅ **動作確認**：
1. ポップアップ右上の「⚙ 設定」を開く
2. 為替レートなどを変えると「100元の商品 → 販売価格」のプレビューが変わる
3. 保存して、次の取り込みから確認画面の自動計算に反映される

> **計算式そのものを変えたいとき**は `lib/price.js` の
> `calculateSellingPrice()` の中身だけを書き換えてください。

## STEP 9：SNS投稿文

✅ **動作確認**：
- 保存完了画面にSNS投稿文が表示され、「📋 投稿文をコピー」でコピーできる
- 保存済み一覧の「SNS文コピー」でも、いつでも同じ文章をコピーできる
- 文章の内容は「⚙ 設定」の「SNS投稿文テンプレート」で自由に変更できる
  （`{{code}}` `{{priceJpy}}` などが商品データに置き換わります）

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| ボタンを押しても何も起きない | ページを一度再読み込み（F5）してから再度押す |
| 価格が取れない | Taobaoの画面構造が変わった可能性。`content/selectors.js` の `price` に新しいセレクタを追加 |
| 画像が少ない | 商品ページを一番下までスクロールしてから取り込む（説明画像は遅延読み込みのため） |
| コード修正が反映されない | `chrome://extensions` で拡張の🔄再読み込み＋商品ページもF5 |

## 将来の拡張について

Googleスプレッドシート・Instagram・X・BUYMA連携などを追加するときは、
`lib/` に新しいファイル（例: `sheets.js`）を追加し、`storage.js` の
`getProducts()` で商品データを読み出して送る、という作りを想定しています。
既存ファイルはほぼ触らずに機能追加できます。
