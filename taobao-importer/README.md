# MAMC Taobao商品取り込み(Chrome拡張機能)

いま自分のブラウザで開いている **Taobaoの商品ページ1件だけ** を、
ボタン1回で「取り込み → 確認・修正 → 保存 → 日本円価格計算 → SNS投稿文生成」まで行う拡張機能です。

## この拡張機能がやらないこと(大事)

- Taobao内の自動巡回・検索結果の大量取得はしません
- バックグラウンドでページを開いたりしません
- CAPTCHAやアクセス制限の回避機能はありません
- 処理が動くのは「ボタンを押したときだけ」で、対象は「いま表示している1ページだけ」です
- パスワードやCookieなどの秘密情報は保存しません

## フォルダ構成(ファイルごとの役割)

```
taobao-importer/
├── manifest.json        … 拡張機能の設定ファイル(Manifest V3)
├── content/
│   ├── selectors.js     … ★Taobaoのセレクタ(取得場所の指定)を全部ここに集約
│   └── extractor.js     … ボタンを押した時だけページに注入される取得処理
├── popup/
│   ├── popup.html       … ポップアップの画面(ボタン・確認画面・一覧)
│   ├── popup.css        … ポップアップの見た目
│   └── popup.js         … ポップアップの動き
├── lib/
│   ├── storage.js       … 保存・管理番号(MAMC-000001)・重複チェック
│   ├── price.js         … ★日本円販売価格の計算式 calculateSellingPrice()
│   ├── sns.js           … ★SNS投稿文のテンプレートと生成
│   └── exporter.js      … JSON / CSV 出力
└── options/
    ├── options.html     … 設定画面(為替レート・送料・利益・テンプレート)
    ├── options.css
    └── options.js
```

**Taobaoの画面構成が変わって取得できなくなったら** → まず `content/selectors.js` だけを修正してください。
**販売価格の計算式を変えたくなったら** → `lib/price.js` の `calculateSellingPrice()` だけを修正してください。
**SNS文を変えたくなったら** → 設定画面から変更できます(コード修正不要)。

## STEP 1:フォルダ・ファイル構成を作る

この `taobao-importer` フォルダ一式がSTEP 1の成果物です。

**確認方法:**
このリポジトリをパソコンにダウンロードします。

1. GitHubのリポジトリページで緑色の「Code」→「Download ZIP」を押す
2. ZIPを解凍して、中の `taobao-importer` フォルダをデスクトップなど分かりやすい場所に置く
3. フォルダの中に `manifest.json` があることを確認する

## STEP 2:Chromeに拡張機能として読み込む

1. Chromeのアドレスバーに `chrome://extensions` と入力してEnter
2. 右上の「**デベロッパーモード**」をONにする
3. 左上の「**パッケージ化されていない拡張機能を読み込む**」を押す
4. さきほどの `taobao-importer` フォルダを選択する
5. 一覧に「**MAMC Taobao商品取り込み**」が表示されれば成功
6. アドレスバー右のパズルピース🧩アイコン → 「MAMC Taobao商品取り込み」の📌を押すと、ツールバーに常時表示されて便利です

> コードを修正したときは、`chrome://extensions` でこの拡張機能の「🔄(更新)」ボタンを押すと反映されます。

## STEP 3:Taobaoの商品ページでボタンを表示する

1. Taobaoで MAMC の商品ページを普通に開く(例: `https://item.taobao.com/item.htm?id=...`)
2. ツールバーの拡張機能アイコンを押す
3. ポップアップが開き、「**この商品を取り込む**」ボタンが表示されれば成功
4. 商品ページを開いていれば緑の文字、それ以外のページでは赤い注意文が出ます

## STEP 4:商品名・価格・URLを取得する

1. 商品ページで「この商品を取り込む」を押す
2. 確認画面に **商品名・現在価格(元)・通常価格・商品URL・商品ID** が入っていれば成功
3. 取得できなかった項目は黄色い警告に表示され、空欄のまま手入力できます

**うまく取れない場合の確認:**
商品ページで `F12` キー → 「Console」タブを開くと、`[MAMC取込]` で始まるログが出ています。
どの項目が取れなかったかが分かるので、`content/selectors.js` のセレクタを直す手がかりになります。

## STEP 5:画像を取得する

1. 商品ページを一度 **下までゆっくりスクロール** してから取り込むのがコツです
   (Taobaoは画面に映った部分の画像だけを読み込むため)
2. 確認画面の下に画像サムネイルが並べば成功
3. 同じ画像は自動で1枚にまとめ、アイコン・ロゴなどは自動で除外しています
4. 不要な画像はチェックを外せます(画像クリックでも切替可)。「すべて選択」「すべて解除」ボタンもあります

## STEP 6:確認画面を作る

1. 取り込み後の確認画面で、商品名や価格を自由に書き換えられることを確認
2. 「キャンセル」で破棄、「この内容で保存する」で保存です
3. ポップアップの外側をクリックして閉じてしまっても、もう一度開けば下書きが復元されます

## STEP 7:保存機能を作る

1. 確認画面で「この内容で保存する」を押す
2. 「保存しました🎉 管理番号:MAMC-000001」と表示されれば成功
3. ホームの「保存済み商品一覧」で確認できます
4. **同じ商品をもう一度取り込むと「この商品はすでに登録されています」と表示される** ことを確認
5. 一覧画面の「JSON出力」「CSV出力」でファイルがダウンロードされます(CSVはExcelでそのまま開けます)

## STEP 8:日本円価格計算を作る

1. 確認画面のオレンジ色の枠に日本円販売価格が自動表示されます
2. 計算式(初期設定):`(人民元価格 × 為替レート22円)+ 送料1,500円 + 利益3,000円` を100円単位で切り上げ
3. ポップアップ右上の「⚙設定」から、為替レート・送料・利益・切り上げ単位を変更できます
4. 数値を変えて保存 → もう一度確認画面を開くと、計算結果が変わることを確認
5. 計算式の構造自体を変えたいときは `lib/price.js` の `calculateSellingPrice()` の中だけを書き換えます

## STEP 9:SNS投稿文を作る

1. 商品を保存すると、完了画面にSNS投稿文が自動生成されます
2. 「SNS投稿文をコピー」でクリップボードにコピー → XやInstagramに貼り付けできます
3. 一覧画面の各商品の「SNS文」ボタンでも、いつでもコピーできます
4. 文面は設定画面の「SNS投稿文テンプレート」で自由に変更できます
   - 使える置き換えワード:`{商品番号}` `{販売価格}` `{カラー}` `{サイズ}` `{商品名}`

## 保存データについて

- 商品データはこのChrome内(`chrome.storage.local`)に保存されます
- Chromeの拡張機能を**削除**するとデータも消えるので、ときどき「JSON出力」でバックアップしてください

## 将来の拡張(設計メモ)

- Googleスプレッドシート等との連携 → `lib/exporter.js` に `productsToXxx()` 関数を追加
- 保存先の変更(スプレッドシート等)→ `lib/storage.js` の関数の中身を差し替え

## よくあるトラブル

| 症状 | 対処 |
|---|---|
| 取り込みが時間切れになる | 商品ページを再読み込みして、ページが完全に表示されてから押す |
| 画像が少ししか取れない | ページを一番下までスクロールしてから取り込む |
| 価格・商品名が取れない | 確認画面で手入力すればOK。頻発するなら `content/selectors.js` を修正 |
| 拡張機能が読み込めない | `manifest.json` があるフォルダ(taobao-importer)を選んでいるか確認 |
| 修正が反映されない | `chrome://extensions` で🔄更新ボタンを押す |
