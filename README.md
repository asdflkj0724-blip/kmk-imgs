# 輝く未来教育 X自動投稿システム

毎朝7時台(日本時間、cronはJST 7:17指定)に、子育て中のお母さんの心に響く言葉を画像付きでXに自動投稿します。
(このリポジトリにはMAMC関連の自動投稿も同居していますが、本READMEは「輝く未来教育」のX投稿についてのみ説明します)

## 投稿の内容

- 小学校受験を考えている保護者向けの**実践的な情報**を、10テーマの順番ローテーションで毎朝投稿
  (面接のNGワード言い換え/時期別の受験準備/面接で黙ったときの対応/毎日5分の面接練習/教育方針の伝え方/兄弟姉妹の質問への答え方/姿勢・手の位置/志望理由3行テンプレート/前日の持ち物/当日朝の習慣)
- 構成は「冒頭フック → 具体的な内容(NG→OK例・手順・声かけ) → 短いまとめ」。同じテーマでも毎回違う具体例
- 正確性ルール: 親が答えを教える・誘導する方法は推奨しない/学校固有の情報は断定しない/作り話の統計は書かない
- ハッシュタグは3個(`#輝く未来教育 #小学校受験` +関連タグ1個のローテーション)
- 3日に1回程度、自然なフォロー案内の一文を自動付与(URLの日は付けない)
- 商品URL付きの一行「学校別の出題傾向・対策はこちら →」は**週1回程度だけ**
- 投稿IDを記録し、**毎週日曜8:17に反応(表示回数・いいね等)とフォロワー数を自動集計**して `reports/` に改善案付きレポートを保存(プロフィールアクセス数はX APIで取得できないため対象外)
- 過去90日分の履歴で重複防止/同日の二重投稿を防止/AI障害時は `fallback.txt` から投稿
- 名言投稿(quotes.csv)は休止中(ファイルは残してあり、再開できます)

## ファイル構成(輝く未来教育 関連のみ)

| ファイル | 役割 |
|---|---|
| `prompt.txt` | オリジナル投稿のルール(トーン・文字数など) |
| `quotes.csv` | 出典確認済みの名言リスト。**出典を確認できたものだけ追加してください** |
| `fallback.txt` | AIが使えないときの予備のオリジナル文 |
| `products.csv` | 「学校別対策ガイド」行のURLが締めの一行に使われます |
| `images/` | 添付画像(ブランド/学校別対策ガイド のフォルダを使用。直近10回の画像は再利用しない) |
| `history.json` | 過去90日の投稿履歴(自動更新。編集不要) |
| `scripts/generate_and_post.py` | 投稿スクリプト |
| `.github/workflows/x-post.yml` | 毎朝の自動実行ワークフロー |

## 必要なGitHub Secrets

| Secret名 | 内容 |
|---|---|
| `X_API_KEY` / `X_API_SECRET` | X APIのKey / Key Secret |
| `X_ACCESS_TOKEN` / `X_ACCESS_TOKEN_SECRET` | X APIのAccess Token / Secret |
| `ANTHROPIC_API_KEY` | Claude APIのAPIキー |

## テスト方法

Actions タブ → 「X Auto Post」→「Run workflow」→ dry_run にチェック → Run。
実際には投稿せず、生成された投稿文をログで確認できます。
