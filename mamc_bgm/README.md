# MAMC リールの BGM

毎日のリール動画には、BGM が自動で付きます（`scripts/mamc_bgm.py`）。

## 既定：自動作曲のオリジナル曲

外部の音源は使わず、プログラムが**毎回その場で作曲**します。

| 項目 | 内容 |
|---|---|
| 権利 | このリポジトリのプログラムが作るオリジナル曲。外部の音源・サンプル素材は一切使っていません |
| 使える範囲 | 商用・SNS 投稿・広告に使えます。クレジット表記は不要です |
| 著作権チェック | 他人の登録曲と一致しないため、Instagram で消音される心配がほぼありません |
| スタイル | ミニマルハウス／ディープ＆シック／ランウェイ（ファッションブランドの広告風） |
| 毎回変わるもの | スタイル・テンポ（112〜126BPM）・キー・コード進行・刻みのリズム・開始位置（直前の投稿とは違うものを選びます） |
| 音量 | -14 LUFS（SNS の標準的な大きさ）・ピーク -1.5 dB。最初0.25秒でフェードイン、最後1.5秒でフェードアウト |

使った曲の設計（スタイル・テンポ・キーなど）は、投稿ごとに `mamc_instagram_history.json` の `bgm` に記録されます。

## 任意：ライセンスを確認した音源を登録する

自分で用意した音源を使いたい場合は、このフォルダに WAV（48kHz・16bit）を置き、`tracks.json` に記録します。
**記録がそろっていない・条件に合わない音源は自動で使われません。**

使える音源は、次のどれかだけです（クレジット不要・商用/SNS/広告で利用可・公開リポジトリに置いても問題がないもの）。

| `license` に書く値 | 例 |
|---|---|
| `CC0-1.0` | CC0（パブリックドメイン提供）と明記された音源 |
| `Public Domain` | 著作権が切れた・放棄された音源 |
| `Owned by FABMIC` | 自社で作曲・制作した音源、または権利を買い取った音源 |

> **Pixabay Music・YouTube オーディオライブラリなどは登録できません。**
> 無料・商用利用可でも、規約で「音源ファイル単体の再配布」が禁止されており、
> このリポジトリは公開されているため、ここに置くと規約違反になるおそれがあります。
> CC BY などクレジット表記が必要な音源も対象外です。

記録の例（`tracks.json`）:

```json
{
  "tracks": [
    {
      "id": "chic-01",
      "file": "chic-01.wav",
      "title": "曲名",
      "source_url": "入手したページのURL",
      "license": "CC0-1.0",
      "license_url": "https://creativecommons.org/publicdomain/zero/1.0/",
      "commercial_use": true,
      "sns_use": true,
      "ad_use": true,
      "attribution_required": false,
      "sha256": "ファイルのSHA-256（sha256sum chic-01.wav で表示される値）",
      "retrieved": "2026-10-21"
    }
  ]
}
```

登録音源がある場合は、約半分の確率で登録音源（直前と違う曲・毎回違う開始位置）、残りは自動作曲になります。

## BGM を止めたいとき

このフォルダに `DISABLED` という名前の空のファイルを置くと、BGM を付けずに無音で投稿します（削除すると元に戻ります）。

## 失敗したとき

BGM の作成・合成・検証のどこかで失敗した場合は、**無音の動画のまま投稿を続けます**（投稿は止まりません）。
理由は GitHub Actions のログに「BGM を付けられなかったため、無音のまま使います」と表示されます。
