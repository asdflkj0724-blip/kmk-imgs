# MAMC リールの BGM

毎日のリール動画には、BGM が自動で付きます（`scripts/mamc_bgm.py`）。
確実に動かすため、**確認済みの3曲を前もって用意し、投稿ごとに順番に流す**方式です。

## 用意している3曲

| ファイル | 雰囲気 |
|---|---|
| `mamc-01-minimal-house.m4a` | ミニマルハウス（A マイナー・120BPM）。4つ打ちとコードの刻みで、洗練されたランウェイ風 |
| `mamc-02-deep-chic.m4a` | ディープ＆シック（C マイナー・115BPM）。やわらかいパッドとアルペジオの大人っぽい雰囲気 |
| `mamc-03-runway-pulse.m4a` | ランウェイ（E マイナー・124BPM）。16分のベースが前に進む、テンポの良い広告風 |

| 項目 | 内容 |
|---|---|
| 権利 | `scripts/mamc_bgm.py` の作曲機能で作ったオリジナル曲。外部の音源・サンプル素材は一切使っていません |
| ライセンス | `Owned by FABMIC`。商用・SNS 投稿・広告に使えます。クレジット表記は不要です |
| 著作権チェック | 他人の登録曲と一致しないため、Instagram で消音される心配がほぼありません |
| 長さ・音量 | 11秒。最初0.25秒でフェードイン、最後1.5秒でフェードアウト。-14 LUFS（SNS の標準的な大きさ） |
| 検証 | AAC 変換で「プチッ」というノイズが出ていないこと、ピークが -1 dB 以下であることを確認済み |

入手元・ライセンス・ハッシュ値・作曲の設計は `tracks.json` に記録しています。
どの曲を使ったかは、投稿ごとに `mamc_instagram_history.json` の `bgm` に記録されます。

## 投稿のときの動き

1. 前回使った曲の**次の曲**を選びます（同じ曲が続きません）
2. 音声は変換し直さずに、動画にそのまま重ねます（変換によるノイズが新しく出ません）
3. 音声の形式・長さ・音量・ピーク・無音区間を検証します。不合格なら次の曲を試します
4. どの曲もだめなとき・曲が見つからないときは、**無音の動画のまま投稿を続けます**（投稿は止まりません）

## 曲を追加・入れ替えたいとき

`tracks.json` に記録がそろっていない・条件に合わない音源は、自動で使われません。使える音源は次のどれかだけです。

| `license` に書く値 | 例 |
|---|---|
| `CC0-1.0` | CC0（パブリックドメイン提供）と明記された音源 |
| `Public Domain` | 著作権が切れた・放棄された音源 |
| `Owned by FABMIC` | 自社で作曲・制作した音源、または権利を買い取った音源 |

> **Pixabay Music・YouTube オーディオライブラリなどは登録できません。**
> 無料・商用利用可でも、規約で「音源ファイル単体の再配布」が禁止されており、
> このリポジトリは公開されているため、ここに置くと規約違反になるおそれがあります。
> CC BY などクレジット表記が必要な音源も対象外です。

必要な記録: `id` `file` `title` `source_url` `license` `license_url` `commercial_use`(true) `sns_use`(true)
`ad_use`(true) `attribution_required`(false) `sha256` `retrieved`。ファイルは 11秒・AAC・48kHz・ステレオの `.m4a` にしてください。

3曲を作り直すときは、手元で `python scripts/mamc_bgm.py build` を実行します（作曲・仕上げ・検証・`tracks.json` の書き直しまで自動）。

## BGM を止めたいとき

このフォルダに `DISABLED` という名前の空のファイルを置くと、BGM を付けずに無音で投稿します（削除すると元に戻ります）。
