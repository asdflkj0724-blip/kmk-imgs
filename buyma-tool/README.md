## 段階1：Chrome拡張

```
extension/
  manifest.json      Manifest V3
  src/extractor.js   ページから情報を取り出す処理（DOMを読むだけ。通信しない）
  src/content.js     タオバオ／天猫の商品ページで動き、ポップアップに結果を返す
  popup.html/js/css  ツールバーのボタンを押したときの画面
tests/
  fixtures/          見本のページ（新しいタオバオ、古い天猫、ログイン画面）
  extractor.test.js  抽出処理のテスト
```

取れるもの：商品名、価格（人民元。割引後があればそちらを優先、幅があれば最小〜最大）、
SKU（色・サイズなどの項目ごとの選択肢、色見本画像、品切れかどうか）、仕様（素材など）、
画像URL（サムネイルの大きさ指定を外して原寸にしたもの、重複なし）。

- サーバーからタオバオには一切アクセスしません。読むのはユーザー本人のブラウザに表示されたページだけです。
- 取れなかった項目は警告として表示します（`complete: false`）。
  スクリーンショットからAIで補う機能は段階2でつなげます。
- 取った結果は拡張の中に最新50件まで保存します（`chrome.storage.local` の `history`）。

### 動作確認の方法

1. Chromeで `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `buyma-tool/extension` フォルダを選ぶ
3. タオバオか天猫の商品ページ（`item.taobao.com/item.htm?id=…` など）を開く。
   拡張を入れる前から開いていたページは、一度再読み込みする
4. ツールバーの拡張アイコン →「この商品の情報を取る」を押す
5. 商品名・価格・SKU・仕様・画像が出ればOK。「JSONをコピー」「JSONを保存」で結果を取り出せる

### テストの実行

Node.js 18以上と Playwright（Chromium）が必要です。

```bash
cd buyma-tool
npm install --no-save playwright   # 入っていない場合のみ
npm test
```

### 注意

テストの見本ページは、タオバオ／天猫のページの作りを手で再現したものです。
本物のページは時期によって作りが変わるので、実際の商品ページで上の「動作確認の方法」を行い、
取れない項目があれば、そのページを保存して `tests/fixtures/` に加え、`extractor.js` を直してください。
