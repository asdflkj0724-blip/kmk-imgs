# BUYMA出品支援ツール（低価格版）

開発指示書「BUYMA出品支援ツール（低価格版）開発指示書」の §9 開発の順番に沿って作っています。

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | Chrome拡張：タオバオ／天猫の商品ページから情報と画像URLを取る | できた |
| 2 | サーバー側でClaude APIを使ってタイトル・説明文を作り、価格計算をつなげる | できた |
| 3 | CSVとZIPの出力（＋BUYMAへの自動入力） | できた |
| 4 | ログイン・データベース・使った回数の管理 | できた |
| 5 | Stripeでの課金と無料お試し（＋紹介制度） | できた |
| 6 | ホームページと規約のページ（＋FAQ・無料ガイド・ブログ） | できた（規約はたたき台） |
| 7 | 自分の出品で実際に使ってテスト → 少人数に先行で公開 | **あなたの作業**：[docs/LAUNCH_CHECKLIST.md](docs/LAUNCH_CHECKLIST.md) |

後から足す機能（指示書 §3-5：在庫・価格の変更チェック、1688対応、チーム利用）はまだ作っていません。

## 全体の形

```
buyma-tool/
  extension/   Chrome拡張（ユーザーのブラウザで動く。タオバオの読み取り・BUYMAへの入力）
  web/         ホームページ＋管理画面＋API（Next.js。Vercel に公開）
    src/app/       画面と API
    src/lib/       価格計算・プラン・AI・禁止ワードなどの中身
    supabase/      データベースの設定（SQL）
    tests/         サーバー側のテスト（npm test）
  docs/        公開までの手順・費用の試算・公開前チェックリスト
  tests/       拡張機能のテスト（npm test）
```

- 公開までの手順：[docs/SETUP.md](docs/SETUP.md)
- AI の費用とプランの利益：[docs/COST.md](docs/COST.md)
- 公開前チェックリスト：[docs/LAUNCH_CHECKLIST.md](docs/LAUNCH_CHECKLIST.md)

## Chrome拡張（extension/）

```
extension/
  manifest.json        Manifest V3
  background.js        ログイン連携の受け取り、出品待ちの順番入力
  popup.html/js/css    ツールバーのボタンを押したときの画面
  options.html/js      設定画面（サーバーURL、自動入力の動き方、画像の大きさ）
  src/extractor.js     タオバオ／天猫のページから情報を取り出す（DOMを読むだけ。通信しない）
  src/content.js       タオバオ／天猫の商品ページで動き、ポップアップに結果を返す
  src/api.js           サーバーのAPIを呼ぶ道具（トークンの保存・自動更新）
  src/zip.js           ZIPを作る道具（外部ライブラリなし）
  src/images.js        画像を取り、大きさをそろえてZIPにする
  src/buyma-config.js  BUYMAの出品画面のURLと、入力欄の見つけ方（ここだけ直せばよい）
  src/buyma-fill.js    BUYMAの出品画面に入力する
tests/
  fixtures/            見本のページ（タオバオ・天猫・ログイン画面・BUYMAの出品画面の見本）
  *.test.js            テスト
```

### できること

1. **情報を取る**：タオバオ／天猫の商品ページで「この商品の情報を取る」を押すと、商品名・価格（人民元）・SKU（色・サイズ、品切れ）・仕様・画像URLを取ります。
   サーバーからタオバオには一切アクセスしません。読むのはユーザー本人のブラウザに表示されたページだけです。
2. **スクショで補う**：取れなかった項目があるときだけ出るボタン。見えている画面を撮って、AIで読み取り、足りない項目だけ補います（画像は拡張で取ったものを使います）。
3. **AIで出品データを作る**：テンプレートと追加の指示を選んで押すと、サーバーで日本語の商品名・商品コメント・販売価格を作ります。
   商品名は文字数（60文字の目安）を数えながら直せます。価格の内訳、禁止ワードやブランド名の注意、AIからの注意も表示します。
   「保存」で直した内容をサーバーに保存、「出品待ちに入れる」で順番入力の対象にします。
4. **画像ZIP**：画像を取り、長い辺を設定のピクセル以下に縮め（拡大はしない）、白背景のJPEGにして
   `taobao_<商品ID>_01.jpg …` の名前で `taobao_<商品ID>_images.zip` に保存します。
   取れなかった画像があっても番号はずらしません（管理画面のCSVの画像ファイル名と並びを合わせるため）。作っている間はポップアップを開いたままにしてください。
5. **BUYMAへの順番入力**：「出品待ちを順番に入力」を押すと、出品待ちを1件ずつBUYMAの出品画面に入力します。
   同時に開くタブは1つだけ。1件ごとに設定の秒数（30秒以上）待ちます。「止める」でいつでも止められます。
   入力した結果は、サーバーの履歴に「BUYMAに入力済み」または「失敗（見つからなかった項目）」として残ります。

### ログインの連携

1. 設定画面（ポップアップ右上の「設定」）で、サーバーのURL（管理画面のサイトのURL）を入れて保存します。
2. 「ログインして連携する」を押すと、サイトの連携ページが開きます。ログインしてから「拡張機能とつなぐ」を押すと、拡張にログイン情報が渡ります。
3. ログイン情報は期限が近づくと自動で更新されます。更新できなくなったら、もう一度2を行ってください。

拡張は、設定画面で保存したサーバーのURLからのログイン情報だけを受け取ります（ほかのサイトからは受け取りません）。
**本番のドメインが決まったら**、`manifest.json` の `externally_connectable.matches` と `host_permissions` にそのドメインを足してください。

### BUYMAへの自動入力の注意（必ず読む）

- BUYMAの出品画面の作りは公開されていないため、**入力欄の見つけ方は推測です**。実際の出品画面で試して、
  見つからない項目があれば `src/buyma-config.js`（出品画面のURL、見出しの文字、予備のセレクタ）を直してください。
- 入力するのは **商品名・商品コメント・価格だけ** です。カテゴリ・ブランド・配送方法・画像は自分で選んでください。
- 動き方は2つ。既定は **「入力だけ（保存は自分で押す）」** です。
  「下書き保存まで自動」は、文字に「下書き」を含むボタンだけを押します。「出品する」「公開」などを含むボタンは押しません。
  入力欄が1つでも見つからなかったときは、下書きボタンも押しません。
- **公開前に、BUYMAの規約で自動入力・自動の下書き保存がどこまで許されるかを確認してください。** 間隔は30秒より短くできません。

### 動作確認の方法

1. Chromeで `chrome://extensions` を開き、右上の「デベロッパー モード」をオンにする
2. 「パッケージ化されていない拡張機能を読み込む」で `buyma-tool/extension` フォルダを選ぶ
   （すでに読み込んでいる場合は、更新ボタンを押す）
3. 設定画面でサーバーURLを入れ、「ログインして連携する」→ ポップアップ上部に「メール｜プラン｜残り件数」が出ればOK
4. タオバオか天猫の商品ページ（`item.taobao.com/item.htm?id=…` など）を開く。拡張を入れる前から開いていたページは再読み込みする
5. 「この商品の情報を取る」→「AIで出品データを作る」→ 商品名・説明・価格が出ればOK
6. 「画像ZIP」でZIPがダウンロードされ、中の画像が開ければOK
7. 「出品待ちに入れる」→「出品待ちを順番に入力」で、BUYMAの出品画面が開き、商品名・商品コメント・価格が入ればOK
   （右上に緑の案内が出ます。赤い案内なら、見つからなかった項目が書いてあります）

### テストの実行

Node.js 18以上と Playwright（Chromium）が必要です。

```bash
cd buyma-tool
npm install --no-save playwright   # 入っていない場合のみ
npm test
```

テストの内容：
- 情報の取り出し（新しいタオバオ・古い天猫・商品ページでないとき）
- ZIP（CRC32の値、`unzip -t` か Python の zipfile で開けること、中身が一致すること）
- BUYMAの自動入力（見出しから欄を見つけて入れること、input/changeイベント、「参考価格」に入れないこと、
  下書きモードで「下書き保存」だけを押し「出品する」「下書き保存して公開」は押さないこと、欄が足りないときは押さないこと）
- APIの道具（401のときに1回だけ更新してやり直す、期限前の更新、上限のエラー文、更新できないときのログアウト）
- 拡張機能そのものを Chromium に読み込めること（manifest の誤りがないこと、画面にエラーが出ないこと）

### 注意

テストの見本ページは、タオバオ／天猫／BUYMAのページの作りを手で再現したものです。
本物のページは時期によって作りが変わるので、実際のページで上の「動作確認の方法」を行い、
取れない・入らない項目があれば、そのページを保存して `tests/fixtures/` に加え、`extractor.js` や `buyma-config.js` を直してください。
