# 公開前チェックリスト（指示書 §7・§9-7）

## 自分の出品で試す（§9-7）

- [ ] `SETUP.md` のとおりに準備し、テストモードの Stripe で動かす
- [ ] タオバオ・天猫の商品ページを、種類を変えて10件以上読み取る（服・バッグ・靴・雑貨、新旧のページ）
- [ ] タオバオ以外（1688、韓国・欧米の通販サイトなど）も数サイト読み取り、AI の抜き出しの精度と1件の費用を確かめる
  - 取れない項目があったらページを保存して `tests/fixtures/` に加え、`extension/src/extractor.js` を直す
- [ ] 作られた商品名・説明文・価格を確認し、気になる点があれば `web/src/lib/ai.ts` の指示文を直す
- [ ] BUYMA の本物の出品画面に、拡張機能の項目をコピーして貼り付け、最後まで出品してみる
  - 足りない項目や、BUYMA の選び方と合わない項目（カテゴリー・配送方法の名前など）がないか確かめる
- [ ] 画像 ZIP の画像が BUYMA に登録できる大きさ・形式か確かめる
- [ ] CSV を Excel で開いて文字化けしないか確かめる
- [ ] `docs/COST.md` の SQL で、1件あたりの実際の AI 費用を確かめ、プランの上限と値段を決める
- [ ] Stripe のテストカードで、申し込み・プラン変更・解約・支払い失敗が正しく反映されるか確かめる
- [ ] 紹介リンクから別のアカウントで登録し、お試しが30日になるか確かめる

## 決めること・確かめること（仮の値になっているもの）

- [ ] サービス名（いまは仮の「ウレルコトバ」。`web/src/site.config.ts`）。J-PlatPat で商標、ドメインが空いているかを確かめる
- [ ] BUYMA の商品名の文字数上限（いまは仮で60文字。環境変数 `BUYMA_TITLE_MAX`）
- [ ] BUYMA の成約手数料率（いまは仮で7.7%。各ユーザーが価格設定で直せる）
- [ ] 禁止ワード・ブランド名の一覧（`web/src/lib/listingRules.ts`）を BUYMA の最新ルールと照らし合わせる
- [ ] 料金・件数（`web/src/lib/plans.ts`。Stripe の価格と同じにする）

## 法律・規約（§7）

- [ ] BUYMA の会員規約（第8条・第10条の2）を読み直し、「データを作って、入力と『出品する』はユーザー本人」という半自動の形で問題ないか確かめる（BUYMA の画面を自動操作する機能は入れていない）
- [ ] 利用規約・プライバシーポリシー・特定商取引法の表記を専門家に確認してもらう（いまはたたき台）
- [ ] 特定商取引法の表記に実際の事業者情報を入れる（`NEXT_PUBLIC_SELLER_*`）
- [ ] 規約・ホームページの「制定日」を入れる
- [ ] BUYMA・タオバオなどのロゴを使っていないか、公式ツールではないと書いてあるか確認する（フッターに記載済み）
- [ ] 画像の著作権について、規約と FAQ に書いてあることを確認する（記載済み）
